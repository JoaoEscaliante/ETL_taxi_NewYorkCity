# ETL_taxi_NewYorkCity
Pipeline de ETL para processamento e análise de dados de táxis de Nova York

# NYC Taxi Data - ETL Pepiline

## Project Overview
Este projeto implementa um pepiline ETL (extração, transformação e carregamento) usando os dados reais.
Foco principal processar os dados transacionais brutos, limpá-los e preparar um ambiente estruturado para análise de dados e business intelligence.

- Extração dos dados em CSV;
- Validação e tratamento de qualidade dos dados;
- Transformação e criação de métricas;
- Agragações para análises;
- Adição do format .parquet;
- Visualização lá no Streamlit.
